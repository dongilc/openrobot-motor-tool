# 관성 튜닝과 새 위치 제어

> [English](position_control.md) | 한국어

펌웨어 261119(Motor Tool v3.9.5)부터 위치 루프를 새 방식으로 돌릴 수 있음. 툴에서는 "새 위치 제어",
터미널 명령은 `or_ctl`. 기본값은 꺼짐이고, 켜지 않으면 이전 펌웨어와 동작이 같음.

대상 보드: SPN-MC V2 / V2R2, SPN-MC D17_D20, SPN-MC D14, VESCAT HIGH V2R2 / V2R3 / V2R4.

## 1. 개요

기존 위치 루프(mcconf `p_pid_kp / ki / kd`)는 위치 오차로만 토크를 냄. 마찰이나 부하를 이기려면 오차가
커져야 하고, 게인을 올리면 오버슈트가 생김. 게인은 구동기와 부하마다 따로 맞춰야 함.

새 위치 제어는 측정한 관성 J 로 게인을 정하고, 전류 지령(A)을 아래 식으로 계산함.

```
iq = kp * (p_ref - p) + kd * (v_ref - v) + J * a_ref + d_hat

kp = J * (2*pi*bw)^2          bw   : 루프 대역폭 (기본 31.5 Hz)
kd = J * 2*zeta*(2*pi*bw)     zeta : 감쇠비     (기본 1.0)
```

- `J * a_ref`: 관성 피드포워드. 목표 가속도에 필요한 전류를 미리 더함.
- `d_hat`: 외란 관측기(DOB, 기본 15 Hz) 출력. 마찰, 중력, 일정 부하처럼 모델에 없는 토크를 추정해 보상함.
  적분항이 없어도 정상상태 오차가 남지 않음.
- kp, kd 가 J 에 비례하므로 부하가 바뀌어도 응답 특성이 같게 유지됨. 단, 부하가 바뀌면 J 를 다시 측정해야 함.

위치 단위는 모터축 각도(deg). 출력축 각도 = 모터축 각도 / 감속비. J 단위는 모터축 기준 A/(deg/s²).

## 2. J 측정 (Inertia Tune)

### Motor Tool

Parameter 탭, Detect Encoder 아래 Inertia Tune 버튼.

1. 보드 연결 후 실제 사용할 부하를 출력축에 고정함. 구동기 단품이면 부하 없이 진행.
2. 출력축이 진폭만큼 양방향으로 움직일 수 있는지 확인. 기본 진폭은 모터축 15°(출력축 15° / 감속비).
3. 측정값을 바로 적용하고 재부팅 후에도 유지하려면 Turn on, Save 체크.
4. Inertia Tune 클릭. 현재 위치를 중심으로 3, 6, 10 Hz 사인 가진을 2회 반복함. 약 30초 + 통신 시간 소요.
   Stop 을 누르면 현재 가진이 끝난 뒤 멈춤.
5. 측정 전류와 위치로 J 를 계산하고 아래 항목을 판정함.
   - 모델과 측정의 일치도
   - 6 Hz, 10 Hz 결과의 일치
   - 1회차, 2회차 결과의 일치
   - 전류 한계 도달 여부
6. 합격이면 J 값과 전송할 명령(`or_ctl j <J>`, `or_ctl on`, `or_ctl save`)을 표시하고, 확인 후 전송함.
   불합격이면 아무것도 적용하지 않음.

불합격은 주로 부하 고정이 불량할 때 발생함(줄에 매단 물체, 커플링 유격, 지그 공진 등). 부하를 고정하거나
진폭을 바꿔 다시 측정.

### ST-Link Tool (양산)

양산 검사 14단계에서 구동기 단품의 J 를 측정하고 새 위치 제어를 켠 뒤 저장함. 재부팅해 저장 여부를 확인하고,
폐루프 주파수 응답과 스텝 응답을 성적서에 기록함. 14단계를 통과하면 새 위치 제어가 켜진 상태로, 건너뛰면
꺼진 상태로 출하됨.

단품 기준으로 튜닝한 구동기를 관절에 조립하면 관성이 커짐. 외란 관측기가 있어 안정성과 위치 정확도는
유지되지만, 설계한 응답을 얻으려면 조립 상태에서 Inertia Tune 을 다시 실행해야 함.

## 3. 명령과 설정

Motor Tool 터미널 또는 VESC Tool 터미널에서 입력.

| 명령 | 범위 | 기본값 | 설명 |
|---|---|---|---|
| `or_ctl` | | | 상태, J, bw, zeta, kp / kd, DOB 추정값, 궤적 가속도 표시 |
| `or_ctl on` / `off` | | off | 새 위치 제어 켜기 / 끄기 (J 설정 필요) |
| `or_ctl j <J>` | 1e-6 .. 1e-3 | 0 | 관성, 모터축 A/(deg/s²) |
| `or_ctl bw <Hz> [zeta]` | 5..60 Hz, 0.5..2 | 31.5 Hz, 1.0 | 루프 대역폭, 감쇠비 |
| `or_ctl dob <Hz>` | 5..30 Hz | 15 Hz | 외란 관측기 대역폭 |
| `or_ctl amax <deg/s²>` | 1000..300000 | 25000 | 0xA4 궤적 가속도 |
| `or_ctl save` | | | 위 설정을 EEPROM 에 저장 |
| `or_ctl clear` | | | 저장값 삭제 (다음 부팅부터 기본값, 꺼짐) |

`or_ctl` 로 바꾼 값은 즉시 적용되지만 `or_ctl save` 하지 않으면 재부팅 시 사라짐. `or_eeprom_default all`
실행 시에도 삭제됨.

설정 기준:
- bw: 올리면 강성과 응답 속도가 커지는 대신 정지 소음이 늘고 기구 공진에 가까워짐. 기본값은 SPN 구동기 기준.
  올릴 때는 조금씩.
- zeta: 1.0 에서 루프 자체의 오버슈트가 없음. 낮추면 응답이 빨라지고 오버슈트가 생김.
- dob: 올리면 부하 변화에 빨리 대응하지만 전류 노이즈가 커짐. bw 보다 충분히 낮게 설정.
- amax: 긴 팔, 매단 부하처럼 흔들리기 쉬운 부하는 낮추고, 빠른 점대점 이동이 필요하면 올림.

## 4. 명령별 동작

| 명령 | 새 위치 제어 사용 시 |
|---|---|
| 0xA4 위치 이동 | 사다리꼴 궤적으로 이동(가속도 `amax`, 최고 속도는 DPS Vmax 설정). 기존 서보 모드와 달리 목표 근처에서 감속이 길어지지 않음. |
| 0xA3 단발 위치 명령 | 작은 변화는 바로 루프에 입력. 위치 오차 전류가 약 3 A 를 넘는 큰 변화는 0xA4 와 같은 사다리꼴 궤적으로 이동. |
| 0xA3 연속 명령 (간격 50 ms 미만) | 명령 주기를 측정해 약 1.5 주기 지연으로 내부 시계에 맞춰 재생함. 명령 도착 시각의 지터가 모터에 전달되지 않음. |
| 0xA2 속도 (DPS) | 같은 내부 루프 사용. |
| MIT (0xC0), 전류 명령 | 영향 없음. |

연속 명령 주기: CAN 은 0xA3 를 1 kHz 까지 누락 없이 수신함. EtherCAT 은 SPN-MC V2 계열에서 0xA3 연속 명령을
2 ms(500 Hz) 주기로 사용.

통신 끊김 감시(`or_wd`)는 기본 설정에서 위치, 속도 명령을 감시하지 않음. 0xA3 / 0xA4 를 한 번만 보내고
위치를 유지해도 됨.

## 5. `or_ctl` 설정과 무관한 변경 사항

- 위치 목표를 제어 루프 안에서 보간하고, D 항을 오차 미분 대신 측정 속도로 계산함. 정지 중 전류 리플이 줄고
  목표 변경 시 전류가 튀지 않음.
- MIT 또는 전류 모드에서 위치 명령으로 전환할 때 현재 위치에서 이어서 시작함.
- 회전 중에 위치 명령이 궤적으로 전환되면 정지 없이 현재 속도에서 궤적을 시작함.

## 6. 동작 확인

```
> or_ctl
or_ctl ON: J 2.511e-05 A/(deg/s^2), bw 31.5 Hz zeta 1.00 -> kp 0.9836 A/deg kd 0.009940 A/(deg/s)
  DOB 15.0 Hz: d_hat 0.142 A, mean |d_hat| 0.150 A; servo trajectory amax 25000 deg/s^2
```

- `ON` 과 설정한 J 가 표시되면 적용된 상태. 저장했다면 재부팅 후에도 같은 값이 나와야 함.
- 정지 중 `d_hat` 은 관측기가 보상 중인 부하(마찰, 중력)임. 부하 변화 없이 시간에 따라 커지면 기구부 점검 필요.
