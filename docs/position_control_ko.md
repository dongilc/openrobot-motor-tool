# 관성 튜닝과 새 위치 제어

> **[English](position_control.md)** | 한국어

펌웨어 261119(Motor Tool v3.9.5)에 위치 루프를 돌리는 두 번째 방식이 추가됨. 툴에서는 **새 위치 제어**,
터미널에서는 `or_ctl` 로 부름. **기본은 꺼짐**이며, 켜기 전까지 보드는 이전과 같이 동작함.

대상 보드: SPN-MC V2 / V2R2, SPN-MC D17_D20, SPN-MC D14, VESCAT HIGH V2R2 / V2R3 / V2R4.

## 1. 무엇이 바뀌나

기존 위치 루프(mcconf `p_pid_kp / ki / kd`)는 위치 오차만으로 토크를 만듦. 마찰을 넘거나 부하를 버티려면
오차가 커져야 하므로, 게인을 세게 잡으면 넘침이 생기고, 구동기와 부하마다 게인을 손으로 찾아야 함.

새 위치 제어는 측정한 숫자 하나, **관성 J** 로부터 전류 지령을 암페어 단위로 바로 계산함.

```
iq = kp * (p_ref - p) + kd * (v_ref - v) + J * a_ref + d_hat

kp = J * (2*pi*bw)^2          bw   = 루프 대역폭  (기본 31.5 Hz)
kd = J * 2*zeta*(2*pi*bw)     zeta = 감쇠비      (기본 1.0)
```

- **관성 피드포워드** `J * a_ref`: 가속에 필요한 전류를 미리 넣어 줌. 축이 먼저 뒤처질 필요가 없음.
- **외란 관측기** `d_hat` (DOB, 기본 15 Hz): 모델로 설명되지 않는 토크(마찰, 중력, 일정한 부하)를 추정해
  상쇄함. 적분항 없이도 목표에 정확히 서고, 매단 부하에도 처지지 않음.
- **게인이 J 를 따라감**: 부하가 무거우면 게인도 비례해서 커지므로 응답 모양이 유지됨. 부하가 바뀌면 J 를 다시 측정할 것.

위치는 모두 **모터축 각도(deg)** 기준임(출력축 = 모터축 / 감속비). J 의 단위는 모터축 기준 A/(deg/s²).

## 2. J 측정 (Inertia Tune)

### Motor Tool

Parameter 탭, Detect Encoder 아래의 **Inertia Tune**.

1. 보드를 연결하고 실제로 쓸 부하를 장착함(맨 구동기면 아무것도 달지 않음). 부하는 출력축에 단단히 고정되어 있어야 함.
2. 출력축이 진폭만큼 양방향으로 자유롭게 움직일 수 있는지 확인. 기본 진폭은 모터축 15°, 출력축에서는 15° / 감속비.
3. 결과를 바로 쓰고 재부팅 뒤에도 유지하려면 **Turn on** 과 **Save** 를 체크한 채로 둠.
4. **Inertia Tune** 을 누름. 보드가 현재 위치를 잡고 그 주위로 3, 6, 10 Hz 사인으로 두 번씩 흔듦.
   약 30초에 통신 시간이 더해짐. **Stop** 을 누르면 진행 중인 흔들기까지만 하고 멈춤.
5. 툴이 측정한 전류와 움직임으로 J 를 풀고 다음을 검사함.
   - 모델이 측정과 얼마나 잘 맞는지
   - 6 Hz 와 10 Hz 에서 같은 J 가 나오는지
   - 두 번의 측정이 일치하는지
   - 전류가 한계에 걸리지 않았는지
6. 합격이면 J 와 보낼 명령(`or_ctl j <J>`, `or_ctl on`, `or_ctl save`)을 보여 주고 확인 후 전송함. 불합격이면 아무것도 적용하지 않음.

불합격은 대개 부하가 단단하지 않을 때 나옴. 줄에 매단 물체, 헐거운 커플링, 지그의 공진 등. 부하를 고정하거나 진폭을 바꿔 다시 시도할 것.

### ST-Link Tool (양산)

양산 검사 14단계가 맨 구동기에서 J 를 측정하고, 새 위치 제어를 켜서 저장함. 재부팅으로 저장을 확인한 뒤
폐루프 주파수 응답과 스텝 응답을 성적서에 남김. 14단계를 통과한 유닛은 새 위치 제어가 켜진 채로 출하되고,
14단계를 건너뛰면 꺼진 채로 출하됨.

맨 구동기로 튜닝한 유닛을 로봇 관절에 조립하면 관성이 커짐. 외란 관측기 덕분에 안정하게 목표에 서지만,
의도한 응답을 얻으려면 관절을 단 상태에서 Inertia Tune 을 다시 돌릴 것.

## 3. 명령과 설정

터미널(Motor Tool 터미널 또는 VESC Tool 터미널):

| 명령 | 범위 | 기본값 | 의미 |
|---|---|---|---|
| `or_ctl` | | | 상태, J, bw, zeta, 계산된 kp / kd, DOB 추정값, 궤적 가속도 표시 |
| `or_ctl on` / `off` | | off | 새 위치 제어 사용 / 중지 (J 필요) |
| `or_ctl j <J>` | 1e-6 .. 1e-3 | 0 | 관성, 모터축 A/(deg/s²) |
| `or_ctl bw <Hz> [zeta]` | 5..60 Hz, 0.5..2 | 31.5 Hz, 1.0 | 루프 대역폭과 감쇠비 |
| `or_ctl dob <Hz>` | 5..30 Hz | 15 Hz | 외란 관측기 대역폭 |
| `or_ctl amax <deg/s²>` | 1000..300000 | 25000 | 0xA4 궤적의 가속도 |
| `or_ctl save` | | | 위 값을 모두 EEPROM 에 저장 (재부팅 후 유지) |
| `or_ctl clear` | | | 저장값 삭제 (다음 재부팅부터 기본값, 꺼짐) |

`or_ctl` 로 바꾼 값은 바로 적용되지만 `or_ctl save` 전에는 재부팅하면 사라짐. `or_eeprom_default all` 도 이 값을 지움.

설정 요령:
- **bw**: 높일수록 단단하고 빠르지만 정지 소음이 커지고 구동기의 기계 공진에 가까워짐. 기본값은 SPN 구동기에 맞춘 값이며, 올릴 때는 조금씩.
- **zeta**: 1.0 이면 루프 자체의 넘침이 없음. 낮추면 응답이 빨라지는 대신 넘침이 생김.
- **dob**: 높일수록 부하 변화를 빨리 잡지만 전류가 거칠어짐. bw 보다 충분히 낮게 유지.
- **amax**: 흔들리는 부하(긴 팔, 매단 부하)는 낮추고, 빠른 점대점 이동이 필요하면 높임.

## 4. 명령별 동작

| 명령 | 새 위치 제어가 켜져 있을 때 |
|---|---|
| **0xA4** 위치 이동 | 목표까지 시간 최적 사다리꼴 궤적(가속도 `amax`, 속도는 DPS Vmax 설정으로 제한). 예전 서보 모드처럼 끝에서 느리게 다가가지 않고 정해진 시간에 도착함. |
| **0xA3** 단발 위치 목표 | 작은 점프는 루프로 바로 감. 위치 오차 전류가 약 3 A 를 넘을 만큼 큰 점프는 전류가 튀는 대신 같은 사다리꼴 궤적으로 감. |
| **0xA3** 스트림 (명령 간격 50 ms 미만) | 펌웨어가 명령 주기를 재고, 자체 시계로 약 1.5 주기 늦게 재생함. 도착 시각의 흔들림이 모터로 가지 않음. |
| **0xA2** 속도 (DPS) | 같은 내부 루프를 씀. |
| **MIT** (0xC0), **전류** 명령 | 영향 없음. |

스트림 주기: CAN 은 0xA3 스트림을 1 kHz 까지 전부 받음. EtherCAT 은 SPN-MC V2 계열 보드에서 0xA3 스트림을 2 ms(500 Hz) 주기로 쓸 것.

통신 끊김 감시(`or_wd`)는 기본 설정에서 위치, 속도 명령을 감시하지 않으므로 0xA3 / 0xA4 를 한 번 보내고 유지해도 됨.

## 5. `or_ctl` 과 상관없이 이번 펌웨어에 들어간 것

- 위치 목표를 제어 루프 안에서 보간하고, D 항을 오차의 변화 대신 측정 속도로 계산함. 정지 중 전류 떨림이 줄고, 새 목표를 줄 때 튀지 않음.
- MIT 나 전류 모드에서 위치 명령으로 바꿀 때 현재 위치에서 매끄럽게 이어짐.
- 움직이는 중에 위치 명령이 궤적으로 넘어가면 먼저 제동하지 않고 현재 속도에서 궤적을 시작함.

## 6. 동작 확인

```
> or_ctl
or_ctl ON: J 2.511e-05 A/(deg/s^2), bw 31.5 Hz zeta 1.00 -> kp 0.9836 A/deg kd 0.009940 A/(deg/s)
  DOB 15.0 Hz: d_hat 0.142 A, mean |d_hat| 0.150 A; servo trajectory amax 25000 deg/s^2
```

- `ON` 과 예상한 J 가 보이면 적용된 상태. 저장했다면 재부팅 뒤에도 같게 나와야 함.
- 정지 중 `d_hat` 은 관측기가 떠안고 있는 부하(마찰, 중력)임. 부하가 그대로인데 시간이 지나며 커지면 기구 쪽 문제를 의심할 것.
